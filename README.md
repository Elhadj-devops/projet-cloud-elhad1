# projet-cloud-elhad1



Projet Cloud : Déploiement AWS avec Terraform
Ce projet est une première implémentation de l'Infrastructure as Code (IaC) pour automatiser le déploiement de ressources sur AWS.

🛠️ Stack Technique
Cloud : AWS

Outil : Terraform (HCL)

🚀 Objectif
Automatiser la création d'une instance EC2 sur la région us-east-1 en utilisant Terraform pour garantir la reproductibilité de l'infrastructure.

📝 Comment utiliser ce projet
Assure-toi d'avoir Terraform installé sur ta machine.

Configure tes accès AWS.

Exécute les commandes suivantes :


terraform init
terraform apply
